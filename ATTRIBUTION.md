Edit that file, not this one.

> **This is a record of what each source states about reuse. It is not legal advice.** Entries marked `verify` have not been read for this project and should be before publishing or redistributing.

## Read these before publishing

- **cBioPortal for Cancer Genomics** — Portal software is open source; the underlying study data carries the terms of its originating consortium.  
  https://www.cbioportal.org/faq
- **RCSB Protein Data Bank** — PDB archive DATA files are free of copyright restrictions (CC0). Images and other content generated by RCSB are published under RCSB's own terms, which are NOT necessarily the same.  
  https://www.rcsb.org/pages/usage-policy
- **GWAS Catalog (EMBL-EBI / NHGRI)** — EMBL-EBI data resources are generally open; confirm the Catalog's own terms.  
  https://www.ebi.ac.uk/gwas/docs/about
- **OncoTree (Memorial Sloan Kettering Cancer Center)** — Not stated in this project — confirm before redistributing.  
  https://oncotree.mskcc.org/
- **WHO / IARC Global Cancer Observatory (GLOBOCAN)** — IARC publishes terms of use for GCO content.  
  https://gco.iarc.fr/

## Notes

### NCI SEER — Surveillance, Epidemiology, and End Results Program

The SEER API needs a government account; this project reads the open Cancer Stat Facts pages instead, which need no key.

### UniProt Knowledgebase (Swiss-Prot)

CC BY requires attribution wherever the data appears — hence the source line in the target drawer, not only in this file.

### RCSB Protein Data Bank

This is the one place the project redistributes binary third-party content rather than linking to it. An earlier version of this codebase asserted the images were public domain; that conflated the PDB archive with RCSB-generated renders. Read the usage policy before publishing, or switch to linking the images rather than committing them.

### openFDA drug label API (US FDA Structured Product Labeling)

Missing from this file until 2026-09-14, although every targets overlay already carried label excerpts.

### ClinicalTrials.gov (NIH / NLM)

NLM asks that the site is not misrepresented as endorsing a use.

### Europe PMC (EMBL-EBI)

Excluding abstracts is a licensing decision as much as a size one. The app links out for text rather than reproducing it.

### WHO / IARC Global Cancer Observatory (GLOBOCAN)

The Start-page numbers the pipeline does not fetch.

### Curated drug pipeline (one per cancer)

Each row carries its own source_url. Not an external dataset.
